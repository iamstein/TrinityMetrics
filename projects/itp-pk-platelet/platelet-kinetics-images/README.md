# Platelet Kinetics Images

Original published figure JPEGs used by `../platelet-kinetics.qmd`.
`sources.json` contains attribution, original figure and image links, DOI,
retrieval date, source-specific reuse status and SHA-256 checksums. The files
are unchanged; the page scales their display. Copyright and licences belong
to the individual sources and are not replaced by the repository licence.

The page distinguishes platelet-count curves from response-duration, dose
and B-cell context. Its notes record visible source inconsistencies and
selection or rescue exclusions that affect interpretation. Full legends
remain linked at the source.

Add contributed figures to `uploads/`, with the provenance described there.
